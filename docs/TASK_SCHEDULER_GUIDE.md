# Windows タスクスケジューラ設定ガイド

`unified_scheduler.py` を PC 起動中ずっとバックグラウンドで動かし続けるための設定手順です。

## 1. 準備

このリポジトリ内に以下のファイルがあることを確認してください。

- `run_scheduler.bat`: 実行用バッチファイル
- `run_hidden.vbs`: サイレント実行用（コマンドプロンプトのウィンドウを表示させない）

## 2. タスクスケジューラの起動

1. Windowsキーを押し、「タスク スケジューラ」と入力して起動します。
2. 右側の「基本タスクの作成...」をクリックします。

## 3. 設定の詳細

- **名前**: `SNS Auto Scheduler`（任意）
- **トリガー**: `ログオン時` または `毎日`
  - おすすめ: `ログオン時` を選択（PC起動のたびに自動で動き出す）
- **操作**: `プログラムの開始`
- **プログラム/スクリプト**: `run_hidden.vbs` を選択します。
  - パス: `<このリポジトリを配置したフォルダ>\run_hidden.vbs`
- **開始 (オプション)**: リポジトリのフォルダパスを入力します（重要）。
  - 例: `<このリポジトリを配置したフォルダ>`

## 4. 動作確認

タスクの一覧から作成したタスクを右クリックして「実行」を選択します。
`posts.csv` に投稿予定があれば、数分以内に投稿されることを確認してください。
（`run_scheduler.bat` を直接ダブルクリックすればウィンドウ付きで動作ログを確認できます）

---

これで、PCを操作していない間もスケジューラーが自動でSNS運用を続けてくれます。
